Study Grade Calculator

Description:
Our program is a Grade Calculator written in Python. The program asks the user for their name and their test score. It then uses the test score to determine the user's letter grade.

The program can calculate grades from A through F based on this scale:

A: 90-100
B: 80-89
C: 70-79
D: 60-69
F: Below 60

The purpose of our program is to show how Python can take user input, process information, and display an output.
